# Lab 07: Grouping Objects

A single-window Java Swing application with three tasks on arrays, loops and matrices.
Use the menu on the left to switch between the tasks.

## Tasks

- **Task 1: Second largest and second smallest.** Finds the largest, second largest, smallest and second smallest elements of an array in one pass, and shows a step-by-step table.
- **Task 2: Matrix multiplication.** Multiplies two matrices using three nested loops. Click a number in the result to see how it was calculated.
- **Task 3: Array equality.** Tests whether two arrays are equal by checking the lengths first and then comparing the elements one by one.

## Classes

- **Lab07App.java**: the main window with the task menu. Run this file.
- **ArrayStats.java** and **ArrayStatsPanel.java**: logic and screen for Task 1.
- **MatrixMultiplier.java** and **MatrixPanel.java**: logic and screen for Task 2.
- **ArrayEquality.java** and **EqualityPanel.java**: logic and screen for Task 3.
- **Ui.java** and **TaskPanel.java**: shared colours, buttons and the common screen interface.

## How to run

1. Put all the files in a package named `lab07`.
2. Run `Lab07App.java`.
